# 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/NazneenRizvi/portfolio-site.git

# Navigate to project
cd portfolio-site

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **http://localhost:3000** in your browser.
